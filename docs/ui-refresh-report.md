# Nursing AI — تقرير إعادة التصميم

## Design Direction

تم تحويل الهوية إلى منصة تعليم تمريضي هادئة وموثوقة: أزرق طبي داكن، سماوي للسياق، أخضر للحالات الإيجابية، مساحات بيضاء واسعة، وحدود خفيفة. بقيت الواجهة عربية RTL وخط Cairo، مع تحسين التسلسل البصري وإيقاع المسافات.

## UI UX Pro Max Findings

استُخدمت المهارة المثبتة محليًا في البحث ضمن مجالات product وcolor وtypography وux وicons، وإرشادات Next.js وshadcn. تم توليد النظام وحفظه في `design-system/nursing-ai/MASTER.md`، ثم تعديل اقتراحاته لتوافق المنتج العربي ومتطلبات التباين وهوية التمريض.

## Brand System

- شعار جديد يجمع كتابًا مفتوحًا ونقطة جاهزية خضراء، دون صليب طبي.
- Primary `#0F5D75`، secondary `#0891B2`، success `#078861`، background `#F6FAFC`، foreground `#102A3A`.
- Cairo للأحرف العربية واللاتينية عبر `next/font`.
- توكنات موحدة للأسطح والحدود والتركيز والحالات والرسوم.
- مكوّنات جديدة قابلة لإعادة الاستخدام: `BrandMark` و`PageHeader` و`EmptyState` و`StatusBadge`.

## Pages Redesigned

- الصفحة العامة: Hero جديد يشرح القيمة ويعرض تجربة دراسة فعلية، خطوات العمل، المزايا، التنويه، والرأس والتذييل.
- المصادقة: الدخول، التسجيل، Google completion، استعادة وتغيير كلمة المرور.
- الطالب: الغلاف والقائمة، الرئيسية، المواد، تفاصيل المادة، المحاضرة، السجل، الحساب، وتفضيلات الدراسة.
- الإدارة: الغلاف المشترك، لوحة الإحصاءات، الطلاب، الإعدادات، الجداول، بطاقات الإحصاء، ورسوم الاستخدام؛ كما وُحّدت المسافات والأسطح عبر باقي صفحات الإدارة.
- نوافذ رفع المحاضرات والمصادر بقيت وظيفيًا كما هي مع تحسين المقاسات والتمرير والحالات.

## Mobile

- تصميم mobile-first مع قائمة جانبية Sheet وارتفاع `dvh`.
- أهداف لمس رئيسية لا تقل عن 44px.
- الجداول والتبويبات الطويلة تمر أفقيًا داخل حدودها.
- حقل المحادثة يحترم `safe-area-inset-bottom` ويبقى ظاهرًا فوق نهاية الرسائل.
- البطاقات والأزرار تتحول إلى أعمدة مناسبة على الهاتف، وتعود لشبكات أوسع على الشاشات الكبيرة.

## Chat

- رأس واضح للمساعد وحالة جاهزية وسياق المادة عند توفره.
- رسالة الطالب مدمجة، ورد المساعد واسع ومهيأ للشرح الطويل.
- Markdown منظم للعناوين والقوائم والاقتباسات والكود والجداول.
- اتجاه `dir="auto"` للمحتوى المختلط عربي/إنجليزي.
- الصور تظهر كاملة بـ`object-contain` وتفتح في معاينة مكبرة.
- حالات التحميل، النسخ، التقييم، الإرسال، الإيقاف ورفع الملفات بقيت كما هي وظيفيًا مع عرض أوضح.

## Accessibility

- تركيز لوحة المفاتيح ظاهر، وعناصر التحكم دلالية وتستخدم Base UI عند توفرها.
- التباين مبني على توكنات أعمق، واللون ليس الوسيلة الوحيدة في التنبيهات والحالات.
- دعم `prefers-reduced-motion`، نص 200%، RTL، الاتجاه الأفقي، والجداول القابلة للتمرير.
- تسميات `aria-label` للأزرار الأيقونية، و`role=status/alert` للحالات المهمة.

## Components

- Core UI: Button، Card، Input، Textarea، Select، Dialog، Sheet، Table، Tabs، Badge.
- Brand/layout: BrandMark، PageHeader، EmptyState، AppShell، SidebarNav.
- Study/chat: ChatView، MessageBubble، Composer، Suggestions، LectureCard، SubjectTrainingTabs، LectureWorkspaceTabs.
- Admin/auth/landing: StatCard، UsageChart، نماذج المصادقة، Hero، Features، HowItWorks، Header، Footer.

## Functional Safety

- لم تُعدل أي ملفات داخل `app/api/` أو `lib/` أو `scripts/` أو `types/`.
- لم تتغير قاعدة البيانات، الاستعلامات، المصادقة، الصلاحيات، AI، OpenAI، prompts، RAG، embeddings، الذاكرة، streaming، payloads، العقود، المسارات أو إعداد Next.js.
- بقيت event handlers وعمليات الرفع والحذف والحفظ والتدريب والاختبارات والحدود كما هي.
- التغييرات محصورة في JSX، classes، المكونات البصرية وحالة معاينة الصورة المطلوبة.

## Remaining Visual Issues

- صفحات الإدارة المتخصصة كثيفة البيانات تحتفظ ببعض التسميات الإنجليزية وألوان الحالات الخاصة بها لأنها مرتبطة بمخرجات تشغيلية حالية؛ التباين والتمرير سليمين.
- لم يُنفذ اختبار وظيفي حي بقاعدة بيانات محلية أو حساب حقيقي لأن `DATABASE_URL` غير متاح محليًا؛ لذلك لم يتم إرسال سؤال AI أو معالجة ملف فعلي في هذه المعاينة.
- لم يُختبر Safari أو جهاز هاتف حقيقي، لكن Chrome غطى جميع العروض المطلوبة والاتجاه الأفقي وتكبير النص.
