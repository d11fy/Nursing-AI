# النسخ الاحتياطي والاستعادة

## ما يُنسخ

`npm run db:backup` ينشئ نسخة `pg_dump` بصيغة custom لقاعدة البيانات كاملة. الملفات الأصلية (المحاضرات، الصور، الإيصالات) مخزنة داخل جدول `stored_files`، لذلك تدخل في النسخة نفسها. يُكتب `latest-backup.json` بجانب النسخة، ويُستخدم كإيصال قبل ترقيات المخطط.

## التكرار والاحتفاظ (المطلوب تشغيلياً)

| البند | القيمة المقترحة | ملاحظة |
|---|---|---|
| نسخة كاملة | يومياً | جدولة على الخادم (cron أو مهمة Dokploy) تشغّل `npm run db:backup` |
| قبل كل نشر يغيّر المخطط | إلزامي | `migrate.mjs` يرفض ترقية قاعدة قائمة دون إيصال نسخة مطابقة (`BACKUP_RECEIPT`) |
| الاحتفاظ | 7 نسخ يومية + 4 أسبوعية + 3 شهرية | تُحذف الأقدم آلياً بعد نجاح النسخة الجديدة |
| مكان الحفظ | خارج خادم التطبيق | قرص أو تخزين منفصل؛ نسخة الخادم نفسه لا تحمي من فقده |
| RPO المقصود | ≤ 24 ساعة | يتحدد بتكرار النسخ |
| RTO المقصود | يُقاس في تمرين الاستعادة | يطبع السكربت `restoreSeconds` |

هذه قيم مقترحة؛ الجدولة الفعلية على خادم الإنتاج لم تُتحقق من داخل هذه البيئة.

## تمرين الاستعادة (آمن)

1. أنشئ قاعدة فارغة منفصلة يحتوي اسمها على `restore` أو `test`، مثل `nursing_restore_test`، على خادم غير خادم الإنتاج إن أمكن.
2. شغّل:

   ```bash
   RESTORE_DATABASE_URL=postgresql://user:pass@host:5432/nursing_restore_test npm run db:verify-restore -- /path/to/nursing-....dump
   ```

3. السكربت:
   - يرفض العمل إذا كانت القاعدة الهدف هي `DATABASE_URL` أو `MIGRATION_DATABASE_URL`.
   - يرفض أي قاعدة لا يحتوي اسمها على `restore` أو `test`.
   - يستعيد النسخة بـ `pg_restore --clean --if-exists --no-owner`.
   - يتحقق من وجود الجداول الحرجة (المستخدمون، الملفات الشخصية، المواد، المحادثات، المحاضرات، المعرفة، حزم الدراسة، الاشتراكات، المدفوعات، الاستخدام، الملفات المخزنة، الإعدادات، البريد) ويطبع عدد صفوف كل منها، وآخر ترحيل مطبق، وغياب ملفات شخصية يتيمة.
4. سجّل زمن الاستعادة وعدد الصفوف، وقارن الأعداد بقاعدة الإنتاج في الوقت نفسه تقريباً.
5. احذف قاعدة الاختبار بعد التمرين.

## الحالة في هذا الإصدار

السكربت والإجراء جاهزان. **لم يُنفَّذ تمرين استعادة فعلي** لأن بيئة العمل هذه لا تحتوي `pg_dump`/`pg_restore` ولا خادم PostgreSQL ولا وصولاً لنسخة إنتاج. يجب تنفيذ التمرين مرة قبل الإطلاق وتسجيل نتيجته هنا.
