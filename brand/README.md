# هوية Nursing AI البصرية

هذا المجلد هو **المصدر الوحيد** لشعار المنصة وأيقونة التطبيق. كل ما يظهر في الموقع وتطبيق الأندرويد يُولَّد منه.

| الملف | الاستخدام |
| --- | --- |
| `logo-symbol.svg` | **الأصل اليدوي**: رمز الشعار (سماعة + دماغ + كتاب) للخلفيات الفاتحة. هذا الملف الوحيد الذي يُعدَّل يدويًا. |
| `logo-symbol-dark.svg` | نسخة الخلفيات الداكنة (الخطوط البيضاء بدل الكحلي). مُولَّد. |
| `app-icon.svg` | أيقونة التطبيق ("الغلاف"): مربع كحلي `#052033` بزوايا مدوّرة يحمل الرمز. مُولَّد. |

## إعادة التوليد

```bash
node scripts/generate-brand-assets.mjs
```

السكربت يكتب الملفات التالية (كلها تُحفظ في git):

- **الويب**: `public/icon.svg`، `public/favicon.ico`، `public/icon-192.png`، `public/icon-512.png`، `public/icon-maskable-512.png`، `public/apple-touch-icon.png`، `public/brand/*` (الرمز بنسختيه + الأيقونة + `og-symbol.png` لصورة المشاركة).
- **تطبيق الموبايل (Vite)**: `mobile/src/assets/brand/*` و`mobile/public/icon.svg`.
- **أندرويد**: `android/app/src/main/res/mipmap-*/ic_launcher*.png` (قديمة ودائرية وأمامية للأيقونة التكيفية)، و`values/ic_launcher_background.xml`، وشاشات البداية `drawable*/splash.png` بكل الكثافات والاتجاهات.

## استبدال الأصل بنسخة أفضل

الأصل الحالي مُستخرج بالتتبع الآلي (vectorization) من صورة JPEG بعرض 1408px، لذلك الحواف نظيفة لكنها ليست رسم المصمم الأصلي. عند توفر ملف الشعار الأصلي (SVG أو PNG عالي الدقة):

1. استبدل `brand/logo-symbol.svg` بالرمز الجديد. يجب أن يحتفظ بالألوان الأربعة نفسها (`#092436` `#225d6a` `#29bac1` `#36cdd7`) وإلا حدّث `ON_DARK` داخل السكربت.
2. شغّل `node scripts/generate-brand-assets.mjs`.
3. لا حاجة لتعديل أي كود آخر.

## ما يحتاج بناء APK جديد

أيقونة التطبيق وشاشة البداية تُحزَّمان داخل الـ APK، فلن تظهر على الهواتف إلا بعد بناء إصدار جديد (`npm run cap:build:release`) ونشره. الشعار داخل شاشات التطبيق (الدخول، التسجيل، الترويسة) يتبع نفس القاعدة لأنه جزء من حزمة الويب المضمّنة في الـ APK.
